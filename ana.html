ANA V.2 — Realni scenario za demo (sa postojećim resursima)

Cilj je da se napravi funkcionalan proizvod za tablet (avatar + glas + odgovori + lead forma), koji se može pokazati i zatvoriti prvi ugovor.

Već postoji: Python/Flask + OpenAI + Telegram + voice
Cilj demo: 1 tablet “kiosk mode” + stabilan flow
Rok: 8–10 nedelja (lean tim)
Polazna tačka MVP za demo Plan i faze Koliko ljudi Budžet Rizici

Polazna tačka (šta imamo danas)

Ovo je realna prednost: AI i kanali već rade. Ne krećem se od nule.

✅ Postojeći resursi

  • Python backend (Flask) + OpenAI integracija
  • Telegram bot + webhook flow
  • Voice kanal (Twilio + TTS) + lead logika
  • SQLite leadovi (kasnije Postgres po potrebi)
  • Sistem i hard gate logika

Šta fali za ANA V.2

  • Tablet UI (kiosk app ili web app)
  • Avatar (3D) sa blendshapes
  • Lip-sync (min. usta se pomeraju)
  • Hardver (1 tablet za demo + stalak)
Najveći rizik: 3D perf + lip-sync
Interno: Za demo je najbrže uraditi tablet kao web app (React + Three.js/R3F) u kiosk browser modu. Time izbacujemo RN učenje i skraćujemo rok.

Plan i faze (realno 8–10 nedelja)

Faze su postavljene tako da svake 2 nedelje imamo nešto što može da se pokaže.

Faza Trajanje Šta isporučujemo Go/No-Go
1) Scope + UX 1 nedelja Flow (lead), demo skripta, UI wireframe, definisane emocije Scope zaključan
2) Tablet UI (web) 2 nedelje Kiosk web app, ekran/dugmad, WS/REST konekcija stub Radi na tabletu
3) Avatar + animacije 2 nedelje Ready Player Me ili custom model, osnovne poze/idle 30 FPS target
4) Lip-sync 2 nedelje Osnovni viseme mapping / Rhubarb pipeline (za demo) Najveći rizik
5) Integracija + polishing 1–3 nedelje Hard gate, lead zapis, stabilnost, demo režim (auto reset) Demo spreman

Koliko ljudi treba (minimalno realno)

Opcije su prilagođene: ja nosim backend + AI + integraciju.

Lean tim (preporuka)

  • Ti (1): Flask API/WS, AI integracija, lead flow, deploy
  • Frontend 3D dev (1): React + Three.js/R3F + perf
  • 3D artist (0.2): model/rig/blendshapes (po potrebi)

Ovo je najrealnije da u 8–10 nedelja izađe demo koji stvarno radi.

Solo (moguće, ali sporo)

  • RN + 3D + lip-sync = veliki rizik
  • Rok realno ide na 4–6 meseci
  • Najviše će pojesti: perf + lip-sync debug
Ako je cilj brz demo — ne preporučujem solo

Budžet (interno, realno)

Cilj je demo koji se prodaje. Ne “konačan proizvod”.

Stavka Varijanta Realno (€)
Tablet (1 kom) + stalak Polovan iPad/Android + basic stalak 600–900
3D avatar Ready Player Me (brzo) ili minimalni custom 0–800
Frontend 3D dev 4–6 nedelja fokus (React + Three/R3F + lip-sync) 2.000–4.500
3D artist (po potrebi) Rig/blendshapes/optimizacija 300–1.200
Server i ops Minimalno (tvoj postojeći hosting) 0–200
UKUPNO (demo) ~3.000–7.000
Idealan scenario: “1.400€ total” je moguće samo ako se nadje jeftin freelancer + gotov avatar + bez realnog lip-sync kvaliteta. Za demo koji stvarno “prodaje”, računaj 3–7k€ i lean tim.

Rizici i mitigacije

Najveći rizici

  • Lip-sync: latency + kvalitet + integracija u 3D
  • Performanse na tabletu: grejanje, FPS drop
  • Scope creep: ubija rok

Mitigacije

  • Web kiosk umesto RN (brže, manje rizika)
  • Ready Player Me avatar (brz start)
  • Go/No-Go posle 2. i 4. faze
