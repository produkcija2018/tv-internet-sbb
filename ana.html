Tablet specifikacije

  • Framework: React Native 0.74
  • 3D Engine: React Three Fiber 8.16
  • Format: glTF 2.0 (.glb)
  • WebSocket: Socket.io client
  • Audio: expo-av 14.0
  • Kamera: expo-camera 15.0
  • Speech-to-Text: @react-native-voice/voice

Bilbord specifikacije

  • LED ekran: 5x3m, P4 (4mm pixel pitch)
  • Renderovanje: NVIDIA Jetson AGX Orin
  • Streaming: RTMP / HLS, 4K @ 30fps
  • Kamera: Hikvision PTZ, 30x zum
  • Mikrofoni: Niz od 8 MEMS (beamforming)
  • Zvučnici: JBL CBT 100LA-LS, 500W

Backend specifikacije

  • Runtime: Node.js 20
  • Framework: NestJS 10
  • WebSocket: Socket.io 4.7
  • Cache: Redis 7
  • Baza: PostgreSQL 16
  • Queue: BullMQ
  • Monitoring: Prometheus + Grafana

3D Model Ane

  • Poligoni: 35,000 (optimizovano)
  • Teksture: 4K (kompresovano)
  • Rig: Humanoid (75 kostiju)
  • Blend Shapes: 52 (FACS sistem)
  • Animacije: 30 (idle, gestovi)
  • Veličina fajla: ~8 MB
  • Glas: Google.sr-RS-Standard-A
