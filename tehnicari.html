Brzi SOP – teren (standard)

                    
Cilj: isti redosled svaki put → manje grešaka.

                    
    
                      
  1. Forward check: DS low/high + tilt (uporedi sa target opsegom).
    2. 
                      
  2. Return clean check: return spectrum (noise floor + pikovi) u tačnom split opsegu.
    3. 
                      
  3. Unity gain / balans: tek kad je return “čist”. Ne maskiraj ingress pojačanjem.
    4. 
                      
  4. Validacija: servis test / modem (ako je moguće) + proveri da li se simptomi ponavljaju.
    5. 
                      
  5. As-built: upiši merenje + šta si menjao (SP2/SP3, atenuator, drop, konektori).
    6. 
                    


                    

                      
Mini checklist (najčešće greške)

                      
    
                        
  • Otvoren port bez 75Ω terminatora
    • 
                        
  • Loš/olabavljen F konektor (mikro prekidi)
    • 
                        
  • Previše pasive “naslagano” (DS rešen, US ubijen)
    • 
                        
  • Neupoređen nivo na 2 tačke (tap vs modem)
    • 
                      

                    

                  


                  

                    
Tilt – šta je i kako ga “uhvatiti”

                    

                      Tilt = razlika između high i low nivoa (npr. 500 MHz vs 120 MHz).
                      Veći tilt često znači da high frekvencije više “trpe” (kabl/pasiva/konektori).
                    

                    
Uzrok → Potvrdi → Akcija

                    
    
                      
  • Uzrok: loš F konektor, oksidacija, loš splitter/pasiva, predugačak drop, loš kabl.
    • 
                      
  • Potvrdi: izmeri low/high na 2 tačke (posle tapa i kod modema). Ako se tilt pogorša nizvodno → drop/pasiva.
    • 
                      
  • Akcija: uradi konektore ponovo, ukloni nepotrebnu pasivu, razmisli o RG11 za duže drop-ove.
    • 
                    

                    

                      
Tip

                      
Tilt se često “maskira” ako gledaš samo jedan kanal. Uvek radi low + high.

                    

                  


                  

                    
Ingress / Leak (Return path)

                    

                      Povrat je najosetljiviji. Ingress (spoljašnji šum) se najčešće vidi kao pikovi ili podignut noise floor u return spektru.
                    


                    
Uzrok → Potvrdi → Akcija

                    
    
                      
  • Uzrok: otvoren port bez 75Ω, loš F konektor, loš splitter u stanu, oštećen drop, korozija.
    • 
                      
  • Potvrdi: radi return scan u tačnom opsegu (npr. stop 65 ili 85). Posmatraj 60–120s (bursty šum).
    • 
                      
  • Akcija: terminatori na otvorene portove, zamena/ponovno krimpovanje konektora, izolacija grane (po proceduri).
    • 
                    


                    

                      
Izolacija (brza)

                      
    
                        
  1. Proveri da li je svaki neiskorišćen port terminisan 75Ω.
    2. 
                        
  2. Vizuelno + rukom proveri F konektore (mikro pomeranje = mikro prekid).
    3. 
                        
  3. Ako procedure dozvoljavaju: odspoji grane jednu po jednu i prati da li šum nestaje.
    4. 
                      

                    

                  


                  

                    
Splitteri / Tap / Pasiva

                    

                      Pravilo: rešavaj DS ciljano, ali pazi da US ne ode previsoko (dodato prigušenje često “gura” modem da jače šalje).
                    


                    
Praktična logika (teren)

                    
    
                      
  • Prejak DS: bolje atenuator ili SP3 unbalanced 7 dB nego 2–3 splittera “u nizu”.
    • 
                      
  • Nejednak nivo: unbalanced splitter koristi “high-loss” izlaz za jaču granu.
    • 
                      
  • Tap izbor: veći dB tap = manji nivo prema korisniku (ali trunk mora biti zdrav).
    • 
                    


                    

                      
Mini “šta upisati” u as-built

                      
    
                        
  • Tap tip + vrednost (npr. 8w17)
    • 
                        
  • Pasiva (SP2 / SP3 balanced / SP3 unbal 7dB)
    • 
                        
  • Atenuator (npr. 6 dB)
    • 
                        
  • Drop (RG6/RG11 + dužina)
    • 
                      

                    

                  


                  

                    
Konektori / Drop kabl

                    
80% “misterioznih” problema su konektori + voda/oksidacija + mikro prekidi.


                    
Uzrok → Potvrdi → Akcija

                    
    
                      
  • Uzrok: loše pripremljen dielektrik, kratko/dugo oklopljenje, labav spoj, voda u F-u.
    • 
                      
  • Potvrdi: “wiggle test” (vrlo blago), vizuelno: pletenica uredna, da li “šeta” konektor.
    • 
                      
  • Akcija: odseci i uradi konektor ponovo; zaštiti spoljašnje spojeve (po vašem standardu).
    • 
                    


                    

                      
RG6 vs RG11

                      

                        Za duže drop-ove, RG11 obično daje manji gubitak (posebno ka višim frekvencijama) — ali je teži za rad i konektore.
                      

                    

                  


                  

                    
As-built & evidencija

                    
Dobar as-built = manje ponovnih izlazaka i brže rešavanje “ponavlja se”.


                    
Šta mora da stoji

                    
    
                      
  • Datum/vreme, lokacija (interno), ime tehničara
    • 
                      
  • Mesto merenja (posle tapa / outlet / modem)
    • 
                      
  • DS low/high + tilt + status
    • 
                      
  • Return opseg + nalaz (peak/noise) + status
    • 
                      
  • Šta je menjano: pasiva/attenuator/konektori/drop
    • 
                      
  • Validacija: rezultat posle intervencije
    • 
                    


                    

                      
Tip

                      
Uvek upiši “pre” i “posle”. To je razlika između slučaja i dokaza.
